## Discover Solutions for Every Task

The Marketplace is Odella's catalog of pre-built AI employees, templates, and workflows. Instead of building everything from scratch, browse for a solution that already matches your business need and put it to work in minutes.

## The Marketplace Page

Reach the Marketplace from the grid icon in the left sidebar (breadcrumb: Home > Marketplace). The hero section reads "Discover Solutions for Every Task," with a **Search AI employees, templates, or workflows...** bar underneath.

## Business Need Categories

Below the hero, a grid of category tiles lets you browse by business need: Sales, Marketing, Customer Success, Finance, Accounting, HR/People, Legal, Compliance, Operations, Product, Engineering, IT/Security, and Admin/Executive. Each tile shows an icon and a template count for that category.

## Browsing: Agents, Templates, and Workflows

A filterable browse area lists everything in the catalog, organized under **All / Agents / Templates / Workflows** tabs:

- **Agents** — pre-built AI employees (e.g., Riley, William, Lisa, Grace, Danielle).
- **Templates** — ready-to-use documents (e.g., NDA, SAFE Note, Tax Invoice, Risk Register).
- **Workflows** — ready-to-use processes (e.g., GitHub API Changelog Publisher, Usage-Billing Reconciler, Feature Release Campaign).

Each card shows the creator (e.g., "Odella") and an install/use count.

## Filtering Your Search

Narrow results using three filter facets: **Business Needs**, **Capabilities**, and **Integration/Apps**.

## Using the Marketplace

The Marketplace is also reachable from inside two setup wizards, using the same underlying catalog:

- **Creating a workflow** — the "From Marketplace" start option. See [Creating a Workflow](/workflow/overview#creating-a-workflow).
- **Adding a worker** — the "Hire from Marketplace" path. See [Adding a Worker](/workforce/overview#adding-a-worker).
