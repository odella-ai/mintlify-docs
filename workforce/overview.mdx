# Build and manage your AI workforce

**Workforce** is where your team creates, hires, and manages AI Employees. Each worker has a defined role, assigned capabilities, working hours, security policies, and work history.

## Workforce overview

The Workforce page lists every worker in your organization. Use it to:

- Search and sort workers
- Review each worker's role and availability
- Start or pause work
- Open a worker's profile or settings
- Add a worker from scratch or hire one from the Marketplace

Worker cards show one of three availability states:

| Status | Meaning |
| --- | --- |
| **Stopped** | The worker is paused and does not accept normal work. |
| **Available now** | The worker is active and currently inside its working hours. |
| **Outside working hours** | The worker is active but outside its configured schedule. Its after-hours policy determines what happens to new requests. |

See [Operations & Logistics](/workforce/settings-operations-logistics) for working hours and after-hours behavior.

### Create manually

Manual setup asks for:

| Field | Guidance |
| --- | --- |
| **Profile image and color** | Choose a visual identity that makes the worker easy to recognize. |
| **Name** | Use a clear, distinct display name. |
| **Role** | Use a short job title that describes the worker's function. |
| **Purpose** | Explain the outcome the worker is responsible for in one or two sentences. |

After creation, open [Identity](/workforce/identity) to set personality, voice, manager, and durable instructions.

## Worker profile

Select a worker to open its profile. The profile brings the worker's capabilities, work, and governance controls together.

| Area | Purpose |
| --- | --- |
| [Skills](/workforce/skill-tree) | View and assign capabilities. |
| [Calendar](/workforce/calendar) | Schedule one-time or recurring work. |
| [Actions](/workforce/actions) | Start work from events in connected applications. |
| [Workspace](/workforce/workspace) | Manage private working files and folders. |
| [Activity](/workforce/activity) | Review work history and operational events. |
| [Identity](/workforce/identity) | Manage profile and durable instructions. |
| [Settings](/workforce/settings-overview) | Configure models, memory, schedule, security, billing, and termination. |

The profile sidebar also provides access to connected inboxes, applications, availability, and current pricing information. See [Worker profile page](/workforce/employee-page) for a detailed layout reference.

## Delegate and review work

Workers can receive work through supported channels such as connected inboxes, workplace messaging applications, scheduled tasks, event-driven actions, and direct conversations in Odella.

<Warning>
  Start with narrow permissions and a clear human review process. Expand access only after the worker produces reliable results on representative work.
</Warning>

## Recommended operating practice

1. Assign one clearly owned responsibility.
2. Connect the minimum required knowledge and applications.
3. Define approval and escalation rules.
4. Test with representative, low-risk work.
5. Review Activity and outputs regularly.
6. Expand responsibilities deliberately.
