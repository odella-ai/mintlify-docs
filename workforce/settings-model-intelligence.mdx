**Model & Intelligence** controls the worker's thinking, media generation, and processing capacity.

## Field reference

| Field                   | What it controls                                                                                                                 | Billing insight                                                                                  |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| **LLM Model**           | The default language model used for conversations, analysis, planning, and tool-assisted work.                                   | Model choice contributes to the hourly quote. Additional usage charges may apply under the worker's plan. |
| **Reasoning Effort**    | How much reasoning the selected model should apply before responding or acting.                                                  | Higher levels can increase token usage and processing time.                                      |
| **Image Generation**    | The default model used when the worker creates images. A task may override it when needed.                                       | Image generation is usage-based and separate from the scheduled hourly rate.                     |
| **Video Generation**    | The default model family used when the worker creates video. A task may select the compatible route for its duration and inputs. | Video generation is usage-based and separate from the scheduled hourly rate.                     |
| **Infrastructure Size** | Processing capacity, queue capacity, and supported concurrent conversations.                                                     | Infrastructure size contributes to the hourly quote.                                             |

The `$` to `$$$$` badges compare relative model cost. They are guidance rather than a fixed per-request price.

## Reasoning effort

| Value      | Best for                                         |
| ---------- | ------------------------------------------------ |
| **Off**    | Fast, simple responses.                          |
| **Low**    | Straightforward work with light reasoning.       |
| **Medium** | A balanced default for most workers.             |
| **High**   | Complex analysis, planning, or careful drafting. |

A higher setting does not guarantee a better result. Start at **Medium**, then increase it only when the role consistently requires deeper analysis.

## Infrastructure size

| Size                 | Best for                                                                                          |
| -------------------- | ------------------------------------------------------------------------------------------------- |
| **Small Instance**   | Personal workflows or a narrowly shared worker. Typically 1–3 people and 1 live conversation.     |
| **Medium Instance**  | A shared team worker used throughout the day. Typically 4–8 people and 2 live conversations.      |
| **Large Instance**   | Broad team coverage or higher-volume shared use. Typically 10–20 people and 4 live conversations. |
| **X-Large Instance** | Heavy enterprise use. 20+ people and 8 live conversations. Contact support for dedicated scaling. |

<Tip>
  Start with the smallest instance that fits expected use. Increase it when more
  people share the worker, work begins queueing, or more live conversations are
  required.
</Tip>

## Defaults and saved models

New workers default to GPT-5.6 Terra, Medium reasoning, GPT Image 2, Seedance 2.0, and a Small Instance unless onboarding sets another configuration.

If a previously selected language model is no longer offered, it remains visible as **Deprecated** so you can review the saved configuration and move to a supported model.
