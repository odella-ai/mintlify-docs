For completed documents, [follow signing requests and retrieve protected records](/documents/signing-records).

**Vault** under Account is for protected credentials. It is not the place to upload general company knowledge.

## Make company files useful to a worker

1. [Create a Document Store](/documents/create-and-configure) with the columns and access rules your collection needs.
2. [Upload or sync documents](/documents/manage-documents), then review extracted metadata and processing status.
3. [Assign knowledge to the worker](/workforce/knowledge).
4. Ask a sample question and verify that the answer uses the expected sources.

Keep shared source material separate from private working drafts. Review [store settings and access](/documents/settings-and-integrations) before adding sensitive files.

## Produce a consistent draft

Choose [PDF](/templates/02_pdf-template) for a fixed layout or [DOCX](/templates/03_docx-template) for a flexible Word document. Configure and test the template, publish it, then [assign it to the worker](/templates/04_using-templates).

[Use a published template](/templates/04_using-templates) with clear source data and review the actual generated file before using it. If signatures are needed, follow the separate [e-signing setup and approval process](/templates/05_e-signing).
