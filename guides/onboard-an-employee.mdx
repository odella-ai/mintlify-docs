## A practical onboarding order

<Steps>
  <Step title="Hire or create the worker">
    Open **Workforce → Add Worker**. Create a worker for your use case or start
    with a ready-to-hire worker from the Marketplace. [Create a
    worker](/workforce/overview) · [Browse the
    Marketplace](/marketplace/overview)
  </Step>
  <Step title="Define the job">
    Set its role, purpose, and durable instructions. State the expected output,
    what it should avoid, and when it should ask a person for help. [Set role
    and instructions](/workforce/identity)
  </Step>
  <Step title="Add context and procedures">
    Connect approved knowledge and assign the skills needed for the job. Use a
    private skill for a reusable company procedure. [Add
    knowledge](/workforce/knowledge) · [Create a
    skill](/workforce/create-a-skill)
  </Step>
  <Step title="Set access and availability">
    Assign an accountable manager, choose who can use and edit the worker, and
    review working hours. Give it only the tools it needs. [Set worker
    access](/workforce/governance) · [Choose tools](/workforce/tools) · [Set
    working hours](/workforce/settings-operations-logistics)
  </Step>
  <Step title="Test one real-shaped task">
    Use sample data and a clear deliverable. Review the result and refine
    instructions before expanding responsibility. [Assign and review
    work](/guides/assign-and-review-work)
  </Step>
</Steps>
